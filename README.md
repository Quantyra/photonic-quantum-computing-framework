# Photonic Quantum Computing Framework

A public component index and integration guide for modular optical hardware and fixed-source photodiode commissioning toward future quantum-photonics experiments. Start with the [integration guide](docs/getting-started.md) to combine a photodiode jig, source fixture and ambient hood on a fixed board.

Current evidence covers component design and reported printing; optical and quantum performance remain unvalidated.

## Use this index

1. Read the [getting-started and integration guide](docs/getting-started.md), including BOM, print orientations, wiring references and commissioning checks.
2. Use the recommended keyed stand and male cradle from the fixture [print and assembly guide](https://github.com/Quantyra/optical-fixture-system/blob/81a1d395f9451685a1b03fb4f69ab38a8cefc0d1/docs/print-and-assembly.md), [STLs](https://github.com/Quantyra/optical-fixture-system/tree/81a1d395f9451685a1b03fb4f69ab38a8cefc0d1/stl), [editable source](https://github.com/Quantyra/optical-fixture-system/tree/81a1d395f9451685a1b03fb4f69ab38a8cefc0d1/cad) and [G-code notes](https://github.com/Quantyra/optical-fixture-system/blob/81a1d395f9451685a1b03fb4f69ab38a8cefc0d1/gcode/README.md). Reuse the unchanged dual V11 jig. Legacy visual edge-alignment stands remain alternatives. For extensions, obtain [spacer downloads](https://github.com/Quantyra/optical-path-spacers/releases/tag/v1.0.0) and the [source and assembly guidance](https://github.com/Quantyra/optical-path-spacers/tree/dfe02f7b79a98e9e71280a49abc08069819b8919). The 25/50/100 mm values are added stop spacing, not overall length or refractive optical path length. This index does not redistribute firmware or G-code.
3. Record the exact component version, commit, variant and paths used. Cite each component archive as well as this guide where relevant; see [citation and contribution instructions](CONTRIBUTING.md).
